# Story 1.19: Chatbot Gestly com OpenAI

## Status

In Progress

## Story

**As a** usuário autenticado do SobControle,
**I want** conversar com a Gestly pelo painel de chat,
**so that** eu receba orientações gerais sobre o uso do sistema sem expor credenciais de API no navegador.

## Acceptance Criteria

1. O painel de chat permite enviar mensagens, mostra o histórico da sessão e apresenta o estado de envio.
2. O frontend chama uma Supabase Edge Function autenticada e nunca contém a chave da OpenAI.
3. A Edge Function valida o usuário autenticado, limita a entrada recebida e chama a Responses API com o segredo `OPENAI_API_KEY`.
4. Falhas de configuração, autenticação ou provedor retornam uma mensagem segura ao usuário, sem vazar segredos.
5. Existem testes unitários para o serviço e a interação principal do painel.
6. Lint, testes e build são executados antes da conclusão.

## Tasks / Subtasks

## Dev Notes

- A chave é configurada somente como segredo da Edge Function (`OPENAI_API_KEY`); nunca usar variável `VITE_*`.
- O modelo inicial é `gpt-5.4-mini`, disponível na conta do projeto e compatível com a Responses API.
- A primeira versão não consulta dados internos da empresa: ela informa a limitação em vez de inventar dados ou executar ações.
