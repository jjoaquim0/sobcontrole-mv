# Escopo de pesquisa

Foram investigados, preferencialmente em documentação oficial:

1. Existência, capacidades, preço e política de dados do DeepSeek V4.
2. Recursos de chat, function calling, JSON estruturado, RAG e documentos na OpenAI.
3. Recursos equivalentes e privacidade comercial do Gemini e Claude.
4. Adequação dos provedores a um SaaS multiempresa com CRM e dados financeiros.
5. Arquitetura mínima para não expor diretamente o banco de dados à IA.

Perguntas de decisão:

- Qual API atende o maior número de recursos com menor complexidade?
- Qual opção é segura para dados de clientes sob a LGPD?
- Em que cenário DeepSeek V4 é vantajoso?
- Como reduzir custo sem entregar qualidade ou segurança?
