# Story 1.8: Superfície diferenciada da Sidebar

## Status

Ready for Review

## Story

**As a** usuário autenticado,
**I want** a sidebar com uma superfície visualmente distinta da área principal
nos temas claro e escuro,
**so that** a navegação tenha melhor hierarquia sem alterar seu comportamento.

## Acceptance Criteria

1. A sidebar usa um token semântico próprio de cor, sem cores hardcoded no componente.
2. No tema claro, a sidebar é um azul-acinzentado claro e perceptivelmente diferente do fundo principal neutro.
3. No tema escuro, a sidebar é uma variação fria e discreta, distinta da área principal.
4. Rotas, colapso, responsividade e acessibilidade atuais não sofrem regressão.
5. Testes, checagem de tipos e build passam.

## Tasks / Subtasks

- [x] Criar o token semântico de superfície da sidebar para os dois temas.
- [x] Aplicar o token exclusivamente no contêiner da sidebar.
- [x] Cobrir a aplicação do token em teste de componente.
- [x] Executar validações de qualidade.
- [x] Remover o contorno horizontal residual do Header sem alterar sua superfície.
- [x] Aplicar divisor vertical de 1px e baixa opacidade entre Sidebar e conteúdo.
