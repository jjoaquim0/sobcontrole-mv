# Pesquisa: API de IA para o Gestly

**Data:** 18 de julho de 2026
**Decisão recomendada:** usar a **Gemini API no plano pago**, com `gemini-2.5-flash` como modelo padrão e `gemini-2.5-pro` apenas para arquivos e análises difíceis.

Ela cobre chat com os dados do CRM, chamadas de funções, respostas estruturadas, pesquisa em documentos, arquivos longos e processamento em lote, sem que o conteúdo do plano pago seja usado para melhorar produtos. DeepSeek V4 é excelente em preço, mas não deve ser o único provedor para dados empresariais identificáveis devido às condições de processamento de dados.
